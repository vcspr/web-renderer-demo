# Web Renderer Demo

A live playground for a declarative JSON block renderer: the kind of format that powers mini-program style screens. Edit JSON on the left, see the rendered result on the right.

## What's inside

- **Live JSON editor** with instant preview
- **Schema validation** with clear, helpful error messages
- **Three built-in examples** to start from
- **Screen navigation** between multiple screens
- **Copy / download / format** controls for the JSON
- **13 working block types**: RichText, Media, Schedule, Map, CrowdDensity, VenueList, Route, Sponsor, Raffle, Hunt, Channel, Pass, and Moments

## Run it

Open `index.html` in any browser. No build step, no dependencies, no server needed.

## Purpose

This is a design exploration: a demo of how declarative JSON can describe rich, interactive screens without writing UI code by hand. Built as a prototype for thinking about mini-program runtimes and connector-driven UI.
